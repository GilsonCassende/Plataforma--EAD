# Perguntas Gerais de Informática e Programação

## 1. Objetivo deste arquivo

Este arquivo reúne perguntas e respostas gerais sobre informática e programação.

Ele foi pensado para ajudar em:

- defesa de projeto;
- revisão teórica;
- entrevistas;
- preparação oral;
- consolidação de fundamentos.

O foco aqui é cobrir temas amplos, como:

- o que é informática;
- o que é programação;
- tipos de linguagem;
- compilação e interpretação;
- baixo nível e alto nível;
- algoritmos;
- estruturas de dados;
- paradigmas;
- sistema operativo;
- memória;
- redes;
- banco de dados;
- segurança;
- web;
- versionamento;
- engenharia de software.

## 2. Informática: perguntas básicas

### 1. O que é informática?
Resposta: Informática é a área que trata do processamento, armazenamento, transmissão e uso da informação com apoio de sistemas computacionais.

### 2. O que é um computador?
Resposta: É uma máquina eletrónica capaz de receber dados, processá-los segundo instruções e produzir resultados.

### 3. Quais são os componentes básicos de um computador?
Resposta: Processador, memória, armazenamento, dispositivos de entrada e dispositivos de saída.

### 4. O que é hardware?
Resposta: Hardware é a parte física do computador, ou seja, os componentes que podem ser tocados.

### 5. O que é software?
Resposta: Software é a parte lógica do computador, ou seja, os programas e instruções que fazem o hardware funcionar.

### 6. Qual a diferença entre hardware e software?
Resposta: Hardware é físico; software é lógico.

### 7. O que é dado?
Resposta: Dado é um valor bruto, ainda não interpretado.

### 8. O que é informação?
Resposta: Informação é o dado já interpretado e com significado.

### 9. O que é processamento?
Resposta: É a transformação de dados em informação através de operações.

### 10. O que é um sistema computacional?
Resposta: É o conjunto de hardware, software, dados e utilizadores a trabalhar em conjunto.

---

## 3. Programação: fundamentos

### 11. O que é programação?
Resposta: Programação é o processo de criar instruções para que um computador execute tarefas.

### 12. O que é um programa?
Resposta: É um conjunto de instruções escritas para serem executadas por um computador.

### 13. O que é código-fonte?
Resposta: É o conjunto de instruções escritas pelo programador numa linguagem de programação.

### 14. O que é programar?
Resposta: É analisar um problema, criar uma solução lógica e escrever essa solução numa linguagem compreensível pelo computador.

### 15. Para que serve a programação?
Resposta: Serve para automatizar tarefas, criar sistemas, resolver problemas e desenvolver aplicações.

### 16. O que é um programador?
Resposta: É a pessoa que desenvolve software por meio de lógica, análise e escrita de código.

### 17. O que é lógica de programação?
Resposta: É a capacidade de organizar instruções de forma sequencial e coerente para resolver um problema.

### 18. O que é um problema computacional?
Resposta: É um problema que pode ser resolvido por meio de instruções executadas por um computador.

### 19. O que significa automatizar uma tarefa?
Resposta: Significa fazer com que uma máquina execute a tarefa de forma automática.

### 20. Programação é só escrever código?
Resposta: Não. Também envolve análise, modelagem, testes, manutenção e resolução de problemas.

## 4. Algoritmos

### 21. O que é um algoritmo?
Resposta: É uma sequência finita e ordenada de passos para resolver um problema.

### 22. Todo programa é um algoritmo?
Resposta: Todo programa implementa um ou mais algoritmos.

### 23. Um algoritmo precisa ser escrito em linguagem de programação?
Resposta: Não. Pode ser descrito em linguagem natural, fluxograma, pseudocódigo ou código.

### 24. O que é pseudocódigo?
Resposta: É uma forma informal e estruturada de descrever um algoritmo sem depender de uma linguagem específica.

### 25. O que é fluxograma?
Resposta: É uma representação gráfica de um algoritmo usando símbolos padronizados.

### 26. Quais características um algoritmo deve ter?
Resposta: Clareza, finitude, ordem lógica e capacidade de produzir resultado.

### 27. O que é entrada em um algoritmo?
Resposta: São os dados que o algoritmo recebe para processar.

### 28. O que é saída em um algoritmo?
Resposta: É o resultado produzido após o processamento.

### 29. O que é processamento em um algoritmo?
Resposta: É o conjunto de operações aplicadas aos dados de entrada.

### 30. Um algoritmo sempre precisa de computador?
Resposta: Não. O conceito de algoritmo existe independentemente da máquina.

## 5. Linguagens de programação

### 31. O que é uma linguagem de programação?
Resposta: É um conjunto de regras e símbolos usado para escrever instruções que o computador pode executar.

### 32. Por que existem várias linguagens de programação?
Resposta: Porque diferentes problemas, contextos e objetivos exigem diferentes ferramentas e estilos.

### 33. O que é sintaxe?
Resposta: É o conjunto de regras de escrita de uma linguagem.

### 34. O que é semântica?
Resposta: É o significado das instruções escritas.

### 35. O que é erro de sintaxe?
Resposta: É um erro na forma de escrever o código.

### 36. O que é erro lógico?
Resposta: É quando o programa executa, mas produz resultado errado por falha no raciocínio.

### 37. O que é erro de execução?
Resposta: É um erro que ocorre enquanto o programa está rodando.

### 38. O que é linguagem de alto nível?
Resposta: É uma linguagem mais próxima da linguagem humana e mais distante da linguagem de máquina.

### 39. O que é linguagem de baixo nível?
Resposta: É uma linguagem mais próxima do hardware e da linguagem de máquina.

### 40. O que é linguagem de máquina?
Resposta: É a linguagem binária entendida diretamente pelo processador.

### 41. O que é Assembly?
Resposta: É uma linguagem de baixo nível que usa mnemônicos para representar instruções de máquina.

### 42. Qual a diferença entre linguagem de máquina e Assembly?
Resposta: Linguagem de máquina usa binário puro; Assembly usa representações simbólicas das instruções.

### 43. Por que linguagens de alto nível são mais usadas?
Resposta: Porque são mais legíveis, produtivas e fáceis de manter.

### 44. Linguagens de baixo nível são inúteis hoje?
Resposta: Não. Elas continuam importantes em sistemas embarcados, drivers, sistemas operativos e otimizações críticas.

### 45. O que é portabilidade de uma linguagem?
Resposta: É a capacidade de o mesmo código rodar em diferentes plataformas com pouca ou nenhuma alteração.

## 6. Linguagens compiladas, interpretadas e híbridas

### 46. O que é uma linguagem compilada?
Resposta: É uma linguagem cujo código-fonte é traduzido previamente para código de máquina ou equivalente executável.

### 47. O que é compilar?
Resposta: É o processo de traduzir código-fonte para outra forma executável pelo sistema.

### 48. O que é compilador?
Resposta: É o programa que realiza a compilação.

### 49. O que é uma linguagem interpretada?
Resposta: É uma linguagem cujo código é executado com apoio de um interpretador, sem gerar necessariamente um executável final tradicional.

### 50. O que é interpretar código?
Resposta: É ler e executar instruções dinamicamente.

### 51. O que é interpretador?
Resposta: É o programa que lê e executa o código.

### 52. Qual a diferença entre compilada e interpretada?
Resposta: Na compilada, o código é traduzido antes da execução; na interpretada, ele é lido e executado com apoio de um interpretador.

### 53. Linguagens compiladas são sempre mais rápidas?
Resposta: Em geral sim, mas depende do caso, da implementação e das otimizações.

### 54. Linguagens interpretadas são sempre mais lentas?
Resposta: Em muitos casos sim, mas essa diferença varia e pode ser reduzida por técnicas modernas.

### 55. O que é uma linguagem híbrida?
Resposta: É uma linguagem que combina características de compilação e interpretação.

### 56. Java é compilada ou interpretada?
Resposta: Costuma-se dizer que é híbrida, porque compila para bytecode e depois esse bytecode é executado pela JVM.

### 57. Python é compilada ou interpretada?
Resposta: Em termos práticos costuma ser tratada como interpretada, embora internamente também produza bytecode.

### 58. C é compilada ou interpretada?
Resposta: C é tradicionalmente compilada.

### 59. JavaScript é compilada ou interpretada?
Resposta: Em termos tradicionais é tratada como interpretada, embora engines modernas também usem compilação JIT.

### 60. O que é bytecode?
Resposta: É uma representação intermediária do código, executada por uma máquina virtual.

### 61. O que é máquina virtual?
Resposta: É um ambiente de execução que abstrai o hardware real.

### 62. O que é JIT?
Resposta: JIT significa Just-In-Time Compilation, ou seja, compilação em tempo de execução.

## 7. Tipos de linguagem e classificação

### 63. Como as linguagens podem ser classificadas?
Resposta: Por nível de abstração, forma de execução, paradigma e domínio de uso.

### 64. O que é linguagem procedural?
Resposta: É uma linguagem orientada à sequência de procedimentos e funções.

### 65. O que é linguagem orientada a objetos?
Resposta: É uma linguagem que organiza o software em objetos com estado e comportamento.

### 66. O que é linguagem funcional?
Resposta: É uma linguagem baseada em funções, imutabilidade e composição.

### 67. O que é linguagem declarativa?
Resposta: É uma linguagem em que se descreve o que se quer obter, sem detalhar tanto como executar.

### 68. O que é linguagem imperativa?
Resposta: É uma linguagem em que se descreve passo a passo como o computador deve agir.

### 69. SQL é linguagem de programação?
Resposta: Sim, é uma linguagem declarativa voltada para manipulação de dados em bancos relacionais.

### 70. HTML é linguagem de programação?
Resposta: Não. HTML é uma linguagem de marcação.

### 71. CSS é linguagem de programação?
Resposta: Não. CSS é uma linguagem de estilo.

### 72. Java e JavaScript são a mesma coisa?
Resposta: Não. São linguagens diferentes, com propósitos e histórias diferentes.

### 73. PHP é uma linguagem de que tipo?
Resposta: É uma linguagem de alto nível muito usada no backend web.

### 74. C é linguagem de alto ou baixo nível?
Resposta: Normalmente é considerada de médio/alto nível com forte proximidade ao hardware.

### 75. Assembly ainda é usado?
Resposta: Sim, em contextos específicos de baixo nível.

## 8. Variáveis, tipos e operadores

### 76. O que é uma variável?
Resposta: É um espaço nomeado na memória usado para armazenar um valor.

### 77. O que é constante?
Resposta: É um valor que não deve mudar durante a execução do programa.

### 78. O que é tipo de dado?
Resposta: É a classificação de um valor, como inteiro, texto, booleano ou decimal.

### 79. O que é inteiro?
Resposta: É um número sem parte decimal.

### 80. O que é float ou real?
Resposta: É um número com parte decimal.

### 81. O que é string?
Resposta: É uma sequência de caracteres.

### 82. O que é booleano?
Resposta: É um valor lógico que pode ser verdadeiro ou falso.

### 83. O que é array?
Resposta: É uma estrutura que armazena vários valores numa coleção.

### 84. O que é operador?
Resposta: É um símbolo que realiza uma operação sobre valores.

### 85. O que é operador aritmético?
Resposta: É um operador usado em cálculos, como soma, subtração, multiplicação e divisão.

### 86. O que é operador lógico?
Resposta: É um operador usado em expressões booleanas, como AND, OR e NOT.

### 87. O que é operador relacional?
Resposta: É um operador usado para comparar valores, como igual, maior ou menor.

### 88. O que é atribuição?
Resposta: É o ato de guardar um valor numa variável.

### 89. O que é escopo de variável?
Resposta: É a região do programa onde a variável pode ser acessada.

### 90. O que é tipagem dinâmica?
Resposta: É quando o tipo pode ser determinado em tempo de execução.

### 91. O que é tipagem estática?
Resposta: É quando o tipo é definido e verificado de forma mais rígida antes da execução.

## 9. Estruturas de controlo

### 92. O que é estrutura condicional?
Resposta: É uma estrutura que permite tomar decisões no programa.

### 93. O que é `if`?
Resposta: É uma estrutura condicional que executa um bloco se a condição for verdadeira.

### 94. O que é `else`?
Resposta: É o bloco executado quando a condição do `if` não é satisfeita.

### 95. O que é `switch`?
Resposta: É uma estrutura de decisão usada para vários casos.

### 96. O que é laço de repetição?
Resposta: É uma estrutura que repete instruções várias vezes.

### 97. O que é `for`?
Resposta: É um laço com inicialização, condição e incremento definidos.

### 98. O que é `while`?
Resposta: É um laço que repete enquanto a condição for verdadeira.

### 99. O que é `do while`?
Resposta: É um laço que executa pelo menos uma vez antes de testar a condição.

### 100. O que é iteração?
Resposta: É cada repetição de um laço.

### 101. O que é `break`?
Resposta: É uma instrução que interrompe o laço ou o `switch`.

### 102. O que é `continue`?
Resposta: É uma instrução que salta para a próxima iteração do laço.

## 10. Funções, métodos e modularização

### 103. O que é uma função?
Resposta: É um bloco reutilizável de código que executa uma tarefa específica.

### 104. O que é um parâmetro?
Resposta: É um valor que a função recebe como entrada.

### 105. O que é argumento?
Resposta: É o valor efetivamente passado para a função no momento da chamada.

### 106. O que é retorno de função?
Resposta: É o valor devolvido pela função ao final da sua execução.

### 107. O que é um método?
Resposta: É uma função associada a uma classe ou objeto.

### 108. Por que usar funções?
Resposta: Para organizar, reutilizar e evitar repetição de código.

### 109. O que é modularização?
Resposta: É a divisão do sistema em partes menores e organizadas.

### 110. O que é reutilização de código?
Resposta: É a capacidade de usar a mesma lógica em vários pontos sem reescrever tudo.

### 111. O que é recursividade?
Resposta: É quando uma função chama a si mesma.

### 112. Quando a recursividade é útil?
Resposta: Em problemas naturalmente decomponíveis em subproblemas semelhantes.

## 11. Programação orientada a objetos

### 113. O que é programação orientada a objetos?
Resposta: É um paradigma que organiza o software em objetos que combinam dados e comportamento.

### 114. O que é um objeto?
Resposta: É uma instância concreta de uma classe.

### 115. O que é uma classe?
Resposta: É um molde que define atributos e métodos dos objetos.

### 116. O que é atributo?
Resposta: É uma característica ou dado pertencente a um objeto.

### 117. O que é método?
Resposta: É uma ação ou comportamento de um objeto.

### 118. O que é instância?
Resposta: É um objeto criado a partir de uma classe.

### 119. O que é encapsulamento?
Resposta: É o princípio de esconder detalhes internos e expor apenas o necessário.

### 120. O que é herança?
Resposta: É o mecanismo pelo qual uma classe herda características de outra.

### 121. O que é polimorfismo?
Resposta: É a capacidade de tratar objetos diferentes de forma uniforme quando compartilham uma interface ou comportamento esperado.

### 122. O que é abstração?
Resposta: É o processo de representar apenas os aspectos essenciais de algo.

### 123. Qual a vantagem da orientação a objetos?
Resposta: Melhor organização, reutilização, manutenção e modelagem de problemas complexos.

## 12. Estruturas de dados

### 124. O que é estrutura de dados?
Resposta: É uma forma organizada de armazenar e manipular dados.

### 125. O que é lista?
Resposta: É uma coleção ordenada de elementos.

### 126. O que é pilha?
Resposta: É uma estrutura do tipo LIFO, ou seja, o último a entrar é o primeiro a sair.

### 127. O que é fila?
Resposta: É uma estrutura do tipo FIFO, ou seja, o primeiro a entrar é o primeiro a sair.

### 128. O que é árvore?
Resposta: É uma estrutura hierárquica de nós ligados entre si.

### 129. O que é grafo?
Resposta: É uma estrutura formada por vértices e arestas que representam relações.

### 130. O que é tabela hash?
Resposta: É uma estrutura usada para acesso rápido a valores com base em chaves.

### 131. O que é matriz?
Resposta: É uma estrutura bidimensional de dados.

### 132. O que é vetor?
Resposta: É um array indexado normalmente de dimensão única.

## 13. Memória e execução

### 133. O que é memória RAM?
Resposta: É a memória principal de trabalho do sistema, usada durante a execução dos programas.

### 134. O que é armazenamento?
Resposta: É onde os dados ficam guardados de forma mais permanente, como HD ou SSD.

### 135. Qual a diferença entre RAM e armazenamento?
Resposta: RAM é temporária e rápida; armazenamento é persistente e geralmente mais lento.

### 136. O que é memória volátil?
Resposta: É a memória que perde os dados quando a energia é desligada.

### 137. O que é memória não volátil?
Resposta: É a memória que mantém os dados mesmo sem energia.

### 138. O que é CPU?
Resposta: É a unidade central de processamento, responsável por executar instruções.

### 139. O que é clock do processador?
Resposta: É a frequência que indica quantos ciclos o processador executa por segundo.

### 140. O que é processo?
Resposta: É um programa em execução.

### 141. O que é thread?
Resposta: É uma linha de execução dentro de um processo.

### 142. O que é multitarefa?
Resposta: É a capacidade de executar várias tarefas de forma concorrente.

## 14. Sistema operativo

### 143. O que é sistema operativo?
Resposta: É o software base que gere hardware, memória, processos, ficheiros e recursos do computador.

### 144. Quais são exemplos de sistemas operativos?
Resposta: Windows, Linux, macOS, Android e iOS.

### 145. Para que serve o sistema operativo?
Resposta: Para gerir os recursos do computador e permitir a execução de programas.

### 146. O que é kernel?
Resposta: É o núcleo do sistema operativo, responsável pela comunicação entre software e hardware.

### 147. O que é sistema de ficheiros?
Resposta: É a forma como o sistema organiza e acede aos arquivos no armazenamento.

### 148. O que é terminal?
Resposta: É uma interface de texto para interagir com o sistema operativo por comandos.

### 149. O que é linha de comando?
Resposta: É o ambiente onde se escrevem comandos textuais para o sistema.

## 15. Banco de dados

### 150. O que é banco de dados?
Resposta: É um sistema organizado para armazenar, consultar e gerir dados.

### 151. O que é SGBD?
Resposta: É o Sistema de Gestão de Banco de Dados.

### 152. O que é tabela?
Resposta: É uma estrutura organizada em linhas e colunas para guardar dados.

### 153. O que é registro?
Resposta: É uma linha da tabela.

### 154. O que é campo?
Resposta: É uma coluna da tabela.

### 155. O que é chave primária?
Resposta: É o campo que identifica unicamente cada registro.

### 156. O que é chave estrangeira?
Resposta: É um campo que cria relação entre tabelas.

### 157. O que é SQL?
Resposta: É a linguagem usada para consultar e manipular bancos relacionais.

### 158. O que é `SELECT`?
Resposta: É o comando usado para consultar dados.

### 159. O que é `INSERT`?
Resposta: É o comando usado para inserir dados.

### 160. O que é `UPDATE`?
Resposta: É o comando usado para atualizar dados.

### 161. O que é `DELETE`?
Resposta: É o comando usado para remover dados.

### 162. O que é um banco relacional?
Resposta: É um banco baseado em tabelas relacionadas entre si.

### 163. O que é NoSQL?
Resposta: É uma família de bancos de dados que não seguem rigidamente o modelo relacional tradicional.

## 16. Web e Internet

### 164. O que é Internet?
Resposta: É a rede mundial de computadores interligados.

### 165. O que é a Web?
Resposta: É um serviço da Internet baseado em páginas e recursos acessados por navegador.

### 166. Qual a diferença entre Internet e Web?
Resposta: A Internet é a infraestrutura de rede; a Web é um dos serviços que funcionam sobre essa infraestrutura.

### 167. O que é um site?
Resposta: É um conjunto de páginas web acessíveis por um endereço.

### 168. O que é uma página web?
Resposta: É um documento acessado via navegador.

### 169. O que é URL?
Resposta: É o endereço de um recurso na web.

### 170. O que é domínio?
Resposta: É o nome legível que identifica um site na Internet.

### 171. O que é IP?
Resposta: É o identificador numérico de um dispositivo numa rede.

### 172. O que é DNS?
Resposta: É o sistema que traduz nomes de domínio em endereços IP.

### 173. O que é servidor?
Resposta: É a máquina ou software que fornece recursos ou serviços a outros sistemas.

### 174. O que é cliente?
Resposta: É o sistema que consome serviços fornecidos por um servidor.

### 175. O que é HTTP?
Resposta: É o protocolo de comunicação usado na web.

### 176. O que é HTTPS?
Resposta: É a versão segura do HTTP, com criptografia.

### 177. O que é frontend?
Resposta: É a parte visual e interativa de uma aplicação.

### 178. O que é backend?
Resposta: É a parte lógica, de processamento e acesso a dados da aplicação.

### 179. O que é API?
Resposta: É uma interface de comunicação entre sistemas.

### 180. O que é JSON?
Resposta: É um formato leve de troca de dados.

## 17. Segurança básica

### 181. O que é segurança informática?
Resposta: É o conjunto de práticas e técnicas para proteger sistemas, dados e redes.

### 182. O que é autenticação?
Resposta: É o processo de verificar quem é o utilizador.

### 183. O que é autorização?
Resposta: É o processo de definir o que o utilizador pode fazer.

### 184. O que é senha forte?
Resposta: É uma senha difícil de adivinhar, normalmente longa e com mistura de caracteres.

### 185. O que é hash?
Resposta: É uma transformação unidirecional usada para representar dados de forma segura.

### 186. O que é criptografia?
Resposta: É a técnica de codificar dados para protegê-los.

### 187. O que é SQL Injection?
Resposta: É um ataque que tenta manipular consultas SQL por entrada maliciosa.

### 188. O que é XSS?
Resposta: É um ataque em que código malicioso é injetado numa página web.

### 189. O que é CSRF?
Resposta: É um ataque que tenta fazer o utilizador autenticado executar ações sem perceber.

### 190. O que é backup?
Resposta: É uma cópia de segurança dos dados.

### 191. O que é restore?
Resposta: É a recuperação dos dados a partir de um backup.

---

## 18. Engenharia de software

### 192. O que é engenharia de software?
Resposta: É a área que aplica princípios de engenharia ao desenvolvimento de software.

### 193. O que é requisito funcional?
Resposta: É uma funcionalidade que o sistema deve oferecer.

### 194. O que é requisito não funcional?
Resposta: É uma característica de qualidade, como desempenho, segurança ou usabilidade.

### 195. O que é modelagem?
Resposta: É a representação estruturada de um sistema ou problema.

### 196. O que é arquitetura de software?
Resposta: É a organização de alto nível dos componentes e suas relações.

### 197. O que é manutenção de software?
Resposta: É o conjunto de alterações e correções feitas após a criação do sistema.

### 198. O que é escalabilidade?

## 20. Perguntas conceituais comuns em defesa

### 213. O que é linguagem de baixo nível?
Resposta: É uma linguagem mais próxima da máquina e do hardware.

### 214. O que é linguagem de alto nível?
Resposta: É uma linguagem mais próxima da linguagem humana e mais abstrata.

### 215. O que é Assembly em poucas palavras?
Resposta: É uma linguagem de baixo nível que representa instruções de máquina com símbolos legíveis.

### 216. O que é linguagem compilada?
Resposta: É uma linguagem cujo código é traduzido antes da execução.

### 217. O que é linguagem interpretada?
Resposta: É uma linguagem cujo código é lido e executado por um interpretador.

### 218. Qual a diferença entre compilador e interpretador?
Resposta: O compilador traduz o programa antes da execução; o interpretador executa lendo o código.

### 219. O que é paradigma de programação?
Resposta: É um estilo ou modelo de pensar e estruturar programas.

### 220. O que é orientação a objetos em poucas palavras?
Resposta: É organizar software em objetos com dados e comportamentos.

### 221. O que é algoritmo em poucas palavras?
Resposta: É uma sequência de passos para resolver um problema.

### 222. O que é banco de dados em poucas palavras?
Resposta: É um sistema organizado para guardar e consultar dados.

### 223. O que é frontend em poucas palavras?
Resposta: É a parte visível da aplicação.

### 224. O que é backend em poucas palavras?
Resposta: É a parte lógica e de processamento da aplicação.

### 225. O que é API em poucas palavras?
Resposta: É uma interface de comunicação entre sistemas.
